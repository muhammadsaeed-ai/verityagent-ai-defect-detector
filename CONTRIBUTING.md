# Contributing

Thanks for helping improve VerityAgent AI Defect Detector.

1. Open an issue describing the defect, use case, or proposed change.
2. Create a focused branch and keep changes small enough to review.
3. Install development dependencies with `pip install -e ".[dev,app]"`.
4. Run `pytest` and `ruff check .` before submitting a pull request.
5. Include a deterministic test for bug fixes where practical.
6. Do not commit private product images, credentials, model weights, or datasets without explicit permission and licensing review.
7. Clearly label synthetic examples and do not describe unvalidated scores as model accuracy.

By submitting a contribution, you agree that it may be distributed under the repository's MIT license.
