# Synthetic demo data

These images are deterministic synthetic illustrations generated by `scripts/create_demo_data.py`.

They are included to verify the reference-comparison pipeline without requiring an external dataset. They are **not** real industrial photographs and their detection results must not be interpreted as production accuracy.

Generate a fresh set with:

```bash
python scripts/create_demo_data.py --output-dir outputs/synthetic-demo-data
```

The generated files are:

- `reference_synthetic.png` — known-good reference.
- `inspection_clean_synthetic.png` — identical clean inspection image.
- `inspection_scratch_synthetic.png` — reference image with a deterministic synthetic scratch.
